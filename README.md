# 🃏 The Dark Wars of Light Clan Bot

Telegram-бот для автоматизации отчётности и контроля дисциплины в клане The Dark Wars of Light.

## 📋 Функционал

- ✅ Приём отчётов по команде `!и 14`
- ⏰ Автоматические уведомления за 6/3/2/1 час до дедлайна
- 📊 Ежедневный отчёт в 03:00 по Омску
- ⚠️ Система предупреждений (<10 очков)
- 🚫 Зона вылета (>3 прогулов)
- 👑 Администрирование через команды
- 📈 Топ-5 игроков и статистика
